# NuvioTV Phone — releases

Signed APKs for my personal Android phone build of
[NuvioMobile](https://github.com/NuvioMedia/NuvioMobile) (GPL-3.0).
The source fork is private; this repository only hosts the build artifacts that
the app's in-app updater reads.

## Install

Download the APK that matches your phone from the
[latest release](https://github.com/roditengosmanteng/nuvio-phone-releases/releases/latest):

| File | Use it for |
|---|---|
| `NuvioTVPhone-<version>-arm64-v8a.apk` | Almost every phone made since ~2016 (64-bit ARM) |
| `NuvioTVPhone-<version>-armeabi-v7a.apk` | Older 32-bit ARM phones |

Android will ask you to allow installing from your browser or file manager the
first time. Later versions install over the top and keep your data, as long as
they come from here — a build signed by anyone else cannot replace this one.

Android only. There is no iPhone build.
